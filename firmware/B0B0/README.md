## 当时的验收情况与边界

获得操作者授权后，先独立验证旧 B0AC，再编程和校验 B0B0，完成独立 Flash 校验并重载。随后实际断开两根板上 USB 和电池，仅用电池冷启动。SiK 记录到 36.454 s 缺口，B0B0 从 199 ms 重新计时；38 个稳定停机快照、1019 个新模块报文和 75 份原始载荷复核通过，操作者确认四电机始终未转。

一分钟静止观察的净漂移为 4.401 mm；此前在不同条件下约 20 s 的 7.4/8.3 cm 漂移记录也一并保留。水平控制采用融合速度 PI，累计位置主要用于显示。单次小漂移或页面上的“XYZ 定点”标签都不能证明实现了绝对位置锁定。

四向拆桨纠偏方向通过；实际带动力 115.2 s，326/577 个运行快照出现混控饱和，因此这次只验收纠偏方向，不能据此验收空中增益。光流旋转分量的严格资格验证、带桨负载和空中稳定性尚未完成，`flight_ready=false`。

此前掉动力由操作者归因为电池松动，这属于操作者提供的说明。最低油门后约 1.7 s 落地锁定被操作者接受为预期行为，相关实现没有改动。历史失败和拒绝文件按原样保留，上述结论对应 10 月 24 日的验收及补充记录。

## 核查与重放

```sh
python tools/verify_recent_export.py
```

命令会验证归档哈希、解压后的采样哈希、51 份源码、选用约束、网表、位流及工程引用，不访问硬件。整个当前顶层/综合网表等价验证没有重新执行；677 项继承证据中，643 项已归档，另 34 项保留原哈希和本地来源。

原始 `source_snapshot/build.tcl` 的综合设置与 `selected_physical/pnr_only.tcl` 的物理收敛设置不同。复现选中物理流程时，在独立输出目录中复制源快照，使用选中 CST/SDC，将已核对网表放入 `impl/gwsynthesis/acg720_ano_port.vg`，再以 Gowin V1.9.12.04 执行 PNR-only TCL。新生成位流应单独验收，不能自动继承当前精确位流的硬件结论。本次上传未重跑全量 Gowin 布线。

安装脚本按原样保存在验证资料中，包含原机器路径、具体下载器和历史回退依赖，不能作为跨机器直接执行的下载入口。下载或固化前需要确认对应硬件状态并取得明确授权。
