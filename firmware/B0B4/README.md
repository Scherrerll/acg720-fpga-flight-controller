# B0B4：高度抗积分饱和与新水平默认值

这是独立于冻结 B0B3 的新版本。2026-10-27 的 `compact_aw_v22/physical_p3r0_01` 已完成真实50MHz离线时序验收，尚未安装到飞机；最终状态以本轮资格和验证收据为准。原 B0B3 固件和证据保留。

用户要求修正最低油门时高度目标下降、总油门却长期保持上限的问题，并将定点模式共享水平默认值设为 **P=0.1000 / I=0.0350**。低空前飞掉高按用户要求不继续处理。

改变集中在：

- `source/position/mtf_xyz_hold_control.v`：Z 积分候选先按原误差、步长及积分范围计算；取得本回调 P 项和更新后的 bias 后，若候选令最终总量超过0..850增量范围，且积分还朝该饱和方向增加，则保留旧积分。反向消积仍允许。同一个被选积分同时用于状态提交和输出，取消时丢弃未提交候选。
- `source/xy_pi_parameters.v`：INIT和reset默认均为wire1000/350，generation从0开始；GET/SET范围、CRC、停机原子提交和重复序号保护保留。参数响应严格标识B0B4。
- `source/build.tcl`：新UserCode=0000B0B4，50MHz约束保持；从选中B3的P3R0/map2/replicate0物理选项开始重新构建。
- 新 `ground/B0B4` 和严格B4 codec：草稿、默认按钮、重启说明与设备默认一致，能力仍需匹配设备查询响应确认。

这组P/I作用于水平速度控制，不是Z环参数。用户后续手动SET仍仅本次上电有效；新固件每次真正复位回到0.1000/0.0350，并未增加Flash参数保存功能。

## 与原P2结构的取舍

普通未饱和回调保留原控制算式。饱和时有意改变原积分行为，阻止继续积累实际输出无法提供的增量；因此不宣称与原P2逐状态完全相同。未增加位置外环、倾角补偿、强制低杆停桨或新的落地判据。原1200运行下限、1250着陆总量阈值、RC/倾角/高度降级与停机写入保护均保留。

为拆分新增比较路径，每个Z回调增加两拍，即50MHz下40ns；PID逻辑步长仍11ms。选中实现已另行通过完整时序验收。

上饱和条件积分避免的是新版本从正常复位开始继续形成旧windup。它不承诺对任意已有积分、任意传感器反馈或任何动力条件立即着陆，也不把离线固定高度测试中的时间作为飞行等待建议。不能用“最低油门后一直等待”替代本次修复和地面验证。

## 地面站与安装

选中配方为 map2、area、综合max_fanout200、replicate0、P3/R0、route_maxfan23；使用完整原始CST/SDC，没有追加DSP位置约束。源55中的50MHz时钟、20ns周期、18个引脚及原radio_rx同步边界保留。时序优化包括同拍发布的AZ/速度范围谓词、原状态门的等价拆分与局部扇出约束，以及Z速度常数乘法的局部logic映射提示；未增加公开发布周期。
