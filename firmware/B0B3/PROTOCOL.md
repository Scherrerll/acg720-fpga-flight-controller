# XY P/I 参数协议 v1

115200 baud，8N1，3.3V TTL，共地。FPGA TX 为 B15/P7-19，新增 RX 为 B16/P7-20；USB TX/M15 继续镜像相同发送流。range_rx/C14 仍属于 MTF。B16 只接收，不驱动电台 TX。选脚依据是现有 `sik_ground/README.md:35–37` 的实际反向通信凭据；旧 `acg720_sik_check` 的 B15/B16 用途相反，不能照搬。该历史凭据不确认此刻实物接线或电平。

所有整数多字节为大端。CRC16/CCITT-FALSE，多项式 0x1021、初始 0xFFFF、不反射、无最终异或，覆盖版本字节起至 CRC 前的所有字节，不含两字节帧头。

| 请求字节 | 含义 |
|---|---|
| 0–1 | A5 90 |
| 2 | 版本 01 |
| 3 | GET=01，SET=02 |
| 4 | 总长度 16（十进制） |
| 5 | 保留，必须 00 |
| 6–9 | uint32 请求序号 |
| 10–11 | uint16 P，公共 P × 10000 |
| 12–13 | uint16 I，公共 I × 10000 |
| 14–15 | CRC16 |

GET 的 P/I 必须为零。SET 总是携带完整一对。P/I 各自合法范围 0..10000，对应公共值 0..1、步长 0.0001。范围是编码与算术边界，不是已验收飞行增益范围。

| 响应字节 | 含义 |
|---|---|
| 0–1 | A5 91 |
| 2 | 版本 01 |
| 3 | 对应请求 opcode |
| 4 | 总长度 24（十进制） |
| 5 | 状态，见下表 |
| 6–9 | 原请求序号 |
| 10–11 | 实际生效 P |
| 12–13 | 实际生效 I |
| 14–17 | uint32 原子生效版本 generation |
| 18–21 | 参数特性实现标识 0000B0B3 |
| 22–23 | CRC16 |

| 状态 | 含义 |
|---|---|
| 0 | GET 成功或 SET 已原子提交；SET ACK 先于发送就已生效 |
| 1 | 版本、长度、保留字节或 GET 负载非法 |
| 2 | CRC 错误 |
| 3 | P/I 越界 |
| 4 | 非停机状态，或等待提交时停机条件撤销 |
| 5 | SET 序号重复/陈旧，未执行 |
| 6 | 不支持的 opcode |

响应总带当次快照的实际生效值，NACK 也如此。不能把旧 ACK 当作当前查询；电脑端同时匹配 opcode/序号、校验 CRC，并在 SET ACK 后独立 GET 比对完整值与 generation。

上电默认 P=500/I=0、generation=0。不实现 EEPROM/Flash 参数保存；本次上电有效，重新启动恢复默认。每次成功 SET（即使值相同）generation 加一。SET 序号在一次上电期间必须严格递增，uint32 不做环绕排序；发生序号回绕时应在明确停机后重新上电或选择更大的显式 `--seq`。已通过 CRC 和格式/opcode 检查的新 SET 会消耗序号，即使随后因范围或锁定被拒绝；重发该拒绝请求不能在解锁条件变化后意外写入。CRC/格式损坏请求不消耗序号。

一个在途请求。收到响应后才发下一个；处理/等待发送期间额外输入不排队，可能丢弃。帧内字节间隔允许小于 25ms，达到 25ms 则丢弃未完整帧并重新寻找 A5 90。UART 帧错误也丢弃未完成帧。噪声、短包、超时不产生伪造成功；无法信任请求身份的截断/失步不回复。完整但 CRC 错误包可回复状态 2。固定 16 字节格式不依据非法长度分配缓冲区，超长垃圾不能溢出。

写入先验证，再等待“取消状态的空闲控制边界”；实际提交边沿再次检查：原始解锁未置位、控制未运行、未起飞、无有效/怠速电机命令、四路真正选择的 PWM 宽度均为停机 1000us。有效遥控的 CH5 解锁开关已高时，即使还在 0.5s 解锁确认计时内也拒绝写入，防止解锁寄存器同一拍置位的竞态；维护时保持 CH5 低/中，无有效遥控且确实停机时也可调参。两个系数同一边沿更新。每次 XY 回调还会同时捕获完整 P/I 对，因此整次运算不会混用。安全条件仅从真实核心与输出宽度取得，不信任滞后的遥测。

TX 使用原有唯一 UART。已开始的整组遥测不能被截断；参数响应在组间发送，已到期遥测优先。现有 A586/A587/A588/A581/A582/A589/A585 的内容、校验与序号保持，旧地面解析器可以继续读取。原遥测中的历史 B0B2 字段为兼容保留，不能单凭该字段识别新镜像；使用新位流 UserCode B0B3、文件 SHA256 和 A591 的特性/协议标识共同确认。

最终发送器直接读取bank已经保持稳定的整帧响应；bank的valid和响应内容一直保留到最后一字节UART真正完成，ready才置位。等待/发送期间bank不接受另一个请求，省去第二份192位复制寄存器，保持一个在途请求的协议。该保持与末字节握手机制已有真实串口波形和背压断言验证。

## 算术与状态

公共单位为 P: deg/(cm/s)，I: deg/(cm/s·s)。RTL 速度为 mm/s，角度为 cdeg；内部增益是公共值 ×10 = wire/1000。速度、误差、积分内部沿用有符号 Q16，不把公共参数重新解释成加速度单位。

- P 项：`round_nearest(ex_q16 * P_wire / 1000)`。默认 500/1000 与原 1/2 精确对应。
- I 项：`I += round_nearest(round_nearest(clip(fix_q16, ±500mm/s) * dt_us / 1e6) * I_wire / 1000)`，每轴输出积分限制 ±1000cdeg；I 不含 P 路的加速度 lead。共享除法器的 `round_nearest` 为就近舍入，恰半时远离零。
- 原 I=0.10 对应 wire=1000、内部乘数 1，恢复后的逐次积分与原 V15 精确对应。
- P+I+前馈中间寄存器扩大到有符号36位Q16；即使最大合法P=1和速度边界，也先保留正确符号再执行原±25°角度夹紧，防止旧32位Q16在32768cdeg处环绕。默认值及原V15参数的数值不因此变化。
- 不起飞的有效光流回调清零 I；I=0 的回调清零且输出不保留积分。停机/取消源状态清零；ATT_STAB 没有光流回调时保留最后完成的积分/滤波状态，取消中的回调恢复上次完整状态，沿用现有语义。
- 参数更改只发生于停机取消边界，此时旧积分已清零；再次进入不继承上一组参数的 I。前馈、加速度反馈、角度限幅和高度环不变。

0.0001 网格上的公共参数可精确编码；CLI 拒绝更细小数，不暗中四舍五入。若把任意实数就近量化到网格，最大系数量化误差为 0.00005（工具不自动做此操作）。真实共享除法器采用就近舍入、恰半远离零；新 I 路两次除法相对未量化单次增量的误差不超过 `(内部I+1)/(2×65536) cdeg/回调`，内部 I 最大10时约 0.000084cdeg/回调，不含原有传感器/三角/滤波量化。最终 `integer_q16` 转整数 cdeg 才朝零截断，与现有路径相同。真实对照证明默认数值输出和原 V15 I=0.10 的积分输出一致。额外串行数学步骤会增加微秒级回调延迟，必须以本任务布线与仿真证据确认完成时限，不能引用旧布线作证明。
