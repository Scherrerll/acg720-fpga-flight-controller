# Idle gain enable refactor: source proof

Baseline: immutable `../response_compact/source`, as bound by `change.json`. Candidate changes one file; the other 54 source files are byte-identical. The edit inserts one independent posedge sampler with the sole enable `state==0`, moves the two existing nonblocking assignments there, and removes them from XY admission. Both16-bit declarations, INIT500/0, all signed casts, arithmetic, states, control priorities and interfaces remain byte-for-byte unchanged.

The equivalence boundary is every declared controller output, including math requests, cancels and operands, for reachable initialized/reset trajectories with synchronous inputs. Direct gain inputs may take any of the65536 values independently, including changing during work; no production-bank range assumption is needed. Clocked behavior is considered after nonblocking assignments settle. Physical timing, asynchronous setup/hold violations, private-state forcing and hierarchical observation of private snapshot values are outside this source proof.

Inductive argument: all state other than work_p/work_i begins equal and has identical next-state expressions except where these gains are read. Their only reads are XY states6,7,64,65,8. Every reachable path to these reads enters through the qualified XY admission with pre-edge state0. On exactly that admission edge both designs capture the same full16-bit P/I pair. Every subsequent active state is nonzero until publication, abort, arithmetic fault or reset, so the candidate sampler is disabled and both designs retain the identical pair at every gain read. Hence their next-state calculations and every public output remain equal. Ordinary idle cycles and Z callbacks may change private candidate snapshots but never read them. The Z graph only reaches20,21,53,22,23,24,60,61,62,54,58,59,55,57,25 and shared waits100/101, then returns0. Shared returns are assigned only by unchanged calc calls; a Z callback cannot enter an XY gain-read state.

Global cancel/origin/blocked and synchronous reset take priority over the FSM and do not consume gains. XY-only cancellation takes priority over the case statement, restores the same saved integral/filter tuple and returns0. Resuming XY must pass its admission edge again, refreshing both gains before use. Divider error sets blocked/state0; subsequent blocked handling cancels it before any new gain read. Late done pulses are ignored outside the shared waits; the real math service additionally masks done on live cancellation and rejects responses from old epochs. The gain edit does not change any math request/cancel/epoch input.

The bank boundary remains `state==0 && cancel`. Bank state2 also rechecks stopped/write-safe conditions. A bank commit edge cannot admit XY because controller cancel has priority. The idle sampler sees the old bank outputs on the commit edge under normal nonblocking semantics, then a subsequent idle/admission edge samples the new atomic pair. No extra callback or output latency is introduced. Navigation passes these wires directly. Parameter responses expose active bank values; no source telemetry/debug output exposes work_p/work_i.

Private waveform caveat: the candidate snapshots track gain inputs on every idle edge, including reset/cancel idle and Z admission. For example, changing idle inputs to123/456 changes the candidate work pair on the next edge while the baseline retains its last callback pair. This is deliberate and is excluded from all-cycle register equivalence. Both initialized declarations remain500/0, and no reset assignment or reset contract is added. The existing guarantee that each active callback holds a coherent pair, including mid-operation input changes, is preserved and remains asserted.

Verification uses the actual immutable old controller (module name changed only for co-instantiation), the actual candidate controller and real shared multiply/divide services. Every public output is compared each cycle; idle private snapshots are not compared. Directed and deterministic random simulation supplements this all16-bit source argument; it is not exhaustive enumeration or a formal solver proof. No PNR/timing/packed-CLS claim follows from source equivalence or synthesis.
