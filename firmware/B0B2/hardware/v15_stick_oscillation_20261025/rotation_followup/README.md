## 为什么需要收紧“缺去旋转”的判断

原 ANO 的 UP_OF 路径采用光流积分、独立积分时长、160 pixel/degree 以及0.00012的光学尺度；基础陀螺滤波之后还增加5 Hz LPF以匹配相位。MTF 输出已经是归一化速度，并非同一种输入，不能直接移植160。

更关键的是，已固定的 FMT 参考代码虽然包含可选陀螺补偿路径，`fmt_ins_interface.c:76` 的 **OPF_FIX_GAIN 默认是0**；其默认路径仍做滤波、坐标和高度换算。因此不能将“参考中存在补偿代码”表述为“该模块默认必须外部扣陀螺”。

[厂商 Micolink 原始说明](https://micoair.com/docs/decoding-micolink-messages-from-mtf-01/)只把 `time_ms` 定义为模块系统时间，说明速度单位/换算，没有定义曝光开始、中心或结束，也没有提供陀螺积分或承诺模块内部补偿算法。V15 `dt_ms` 是相邻模块时间戳的差，**不能当作已知曝光窗**。A589仅为 FPGA 收帧时抓取最新的四级过滤后gyro；不是曝光同步积分，当前约5 Hz下传不能反演精确相位。

现有旧手持俯仰记录累计位移很小，同样说明“任何姿态变化都必然产生固定系数的大伪位移”的说法过强；因未独立约束光心平移，既不能证明内部补偿，也不能用于拟合系数。

## 尚可定位的动态差异与下一步

1. 原融合按20ms运行；V15预测随加速度回调、纠正随新MTF包运行。名义Kp/Ki相同不保证完整离散相位/采样保持相同。原智能光流 of_ok 支路给P和I的反馈也不同于当前纯融合速度。
2. 光流倾角越过15°会退出并重置速度融合，控制器保留已完成的PI/滤波状态；两次实飞越界退出/恢复已记录。它可放大扰动，但本次起振时目标角本来低于12°，仅限幅到12°无法改变该起振阶段。
3. 当前速度按斜距缩放，FMT使用`distance*cos(roll)*cos(pitch)`；在各轴15°内，单轴差约3.53%、双轴约7.18%。这项差异可核实，但不能据此独自解释大幅振荡。
4. 若要将旋转污染与真实平移分离，下一份有判别力的证据需要**约束/测量光心位置的固定转轴、明确的旋转/平移对照**，并据此检查尺度和相位。再重复无位置约束的手持动作不能完成这个辨识。另一条独立分离路径是先确认姿态内环的带载小信号动态，再判定外环/测量链的阻尼；当前数据不支持声称内环已经完全排除。

本轮检查到此结束；PID、产品源码、已固化位流均未改动，没有综合、布线、下载或Flash操作。V16/V17继续暂停。后续修复应由可区分的证据驱动，当前不应以“降低PID”或“直接加去旋转”替代根因辨识。
