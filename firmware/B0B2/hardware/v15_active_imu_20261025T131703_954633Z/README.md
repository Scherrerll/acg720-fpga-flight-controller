固定机架没有随升高指令运动，记录到总油门升高及混控限幅；这类拆桨记录不能用于验收空中增益、带载振动或悬停精度。本次只验证已安装 V15 在短时主动控制和电机提速时的 IMU 数据连续性。主帧只有约 5 Hz，计数来自板端诊断，主机没有逐个接收到所有 1 kHz IMU 样本。

整段主遥测 370 帧，缺失 8 帧、CRC 错误 0、丢弃字节 205。MTF 模块校验、长度、UART、超时、缺样、重复及重启计数均无新增。记录器当次最终检查无错误、丢弃记录块/字节为 0。
