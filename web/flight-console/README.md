## 构建与验证

本地验证时，20 项 Node 测试和 16 项 Python 测试全部通过。Node 需要 20.18+，可运行 `npm ci`、`npm run build` 和 `npm test`；Python 检查在 `local/` 目录下运行 `python -B -m unittest test_bridge.py`。后端本地测试使用内存存储，不连接云平台。

云存储初始为空时的 fresh=false 检查已在开启实时转发前通过。冒烟脚本目前仅允许准确的 `https://test.gmflylog.com` 与 `https://gmflylog.com` 两个来源，日志写入只使用合成样本；对当前公开实时状态只读并检查 schema/share 模式及布尔 freshness，不覆盖正在更新的遥测。主域名证书已就绪，完整冒烟与清理已执行通过。另用12000样本合成日志验证了上传200、读取样本数及首尾值、CSV 12000行和删除后404。

完整合成 API 冒烟在同一运行时修复的先前部署 `dpsnx…` 上通过。移除临时鉴权探针后，最终部署 `dpuiqjnbrjkm` 再次确认 health 200 和有效 fresh live 200；最终代码不包含临时诊断接口。

EdgeOne 会把原生 Request 的 `.body` 遮蔽为解析后的数据，并把 `.signal` 遮蔽为 undefined。云函数适配层通过 `Request.prototype.body` 原生 getter 取得真实流，再使用 URL、method、headers 和 body 重建标准 Request，避免复制被运行时遮蔽的属性后造成 JSON/gzip 请求错误。该兼容处理已有测试覆盖。

平台 `/api/health` 已实测返回 `storage_ready:true`。前端源码模块仍为 `.mjs`；构建时生成 `.js` 副本并重写发布引用。已确认平台返回正确的 JavaScript MIME，避免浏览器拒绝加载模块。

构建产物 `public/` 只包含静态文件，部署时还需要平台云函数源码、`platform/`、`worker/` 和相关依赖，不能只上传 `public/` 作为纯静态站。

## 开通和部署

1. 用户本人登录腾讯 EdgeOne Makers，按页面要求完成账号实名与服务条款；选择当前免费版，不开通付费模式或自动升级。注册、条款和任何付费变更需用户本人确认。
2. 建立独立测试项目，通过私有代码仓库或官方CLI部署本目录。只提交代码与资源，不提交 `node_modules`、`.env`、本地日志和密钥。
3. 项目构建命令 `npm run build`，输出 `public`；`edgeone.json` 已配置 Node 云函数及境外香港区域。未备案域名先使用“全球（不含中国内地）”区域，能否从目标网络访问必须实测；香港区域不构成国内可达性保证。中国内地节点需先满足ICP备案要求。
4. 平台环境变量配置新 `PUBLISH_TOKEN`，Blob命名空间 `gmfly-flight` 由SDK首次使用创建。先检查临时域名 `/api/health` 和 `/api/live`。首次没有数据时应显示未连接，不能伪造在线。
5. 新候选 bridge 使用新域名和对应新令牌，通过已有隐藏标准输入启动流程配置；默认保持分享关闭。需要并存测试 bridge 时使用不同本地端口；当前正式 relay 仅保留8766。不能停止串口接收器，也不能同时占用同一端口。
6. 临时域名验收：页面与全部图标加载正常；无令牌POST返回401；只读访问无飞机控制功能；启动实时分享后时间和状态更新，停止后按真实时间过期；选定日志上传、样本数和CSV一致，重载后仍可读。分别用关闭VPN的手机蜂窝和Wi-Fi验证。合成 API、云函数存储与 gzip 日志请求已进行平台实测；响应线路压缩未验证；实际日志仍由用户逐条选择分享，避免把测试结果当作任意真实日志完整性承诺。
7. 实测通过后才把 `gmflylog.com` 切到平台实际提供的新CNAME/验证记录；不要猜记录值，也不要提前删除旧Sites绑定。记录旧DNS方便回退；旧站与本地原始日志保留。

## 免费额度和回退

归档时参考的官方额度为：Node 云函数 100 万次/月、50 万 GB-s/月，Blob 账号存储 1 GB，云函数请求/响应 6 MB。按 1 Hz 发布、3 个 1 Hz 观看页、每天 2 小时、持续 30 天计算，主接口约需 86.4 万次请求，还要为对时、日志和重试留出余量。多人同时查看或全天运行时不宜沿用这个预算；实际 CPU/内存耗时和平台面板数据为准，不依赖试运行超限宽限。

实时快照只覆盖一个键，不累计存储；日志仅分享选定的记录。接近容量上限时先下载备份，再由用户选择撤销分享以释放空间。免费额度或计费方式变化时需要重新确认，不能静默转为付费。

需要回退时，恢复 bridge 地址、令牌和已修改的 DNS，并保留新平台数据以便核对。旧云日志没有自动迁移到此候选，可从本地重新选择分享，同时检查来源和完整性标记。
