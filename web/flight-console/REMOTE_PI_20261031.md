# 网站参数调节与地面站界面 · 2026-10-31

## 交付范围

本地 `ground/B0B4` 的实时、日志、P/I页面统一使用官网深色背景、蓝色强调色、GM-FLY顶栏和侧栏。网站新增 `/parameters`，提供设备查询、成对编辑共享XY速度P/I、仅填入草稿的默认值按钮及写后读回；两端均明确区分草稿和设备实际值。范围各0～1、最多四位小数，不舍入。此入口没有开放姿态环、高度环或其他PID；不更换固件，不保存Flash，断电恢复固件默认值。

目前交付是本地实现和离线验证，没有发布到gmflylog.com，没有设置云端控制密钥，没有连接串口或向实体设备发参数。实时遥测分享与原有本地记录保持原通路。

## 工作方式

```text
浏览器 /parameters（独立控制密钥，仅内存）
  → 同源云API（认证、8秒请求有效期、连接身份及generation校验）
  ← 本地主动出站remote_pi.py（一次性challenge，仅查询/成对SET）
  → 已有loopback地面站API（唯一串口所有者、停机检查）
  → FPGA参数协议（最终硬件资格检查）
  → ACK后独立GET → 同一连接/参数对/下一代generation核对 → 浏览器完成
```

排队或收到HTTP 202均不表示设备已写入。地面响应丢失、超时、断线、身份变化、读回不符会显示结果未知并撤销写入资格，必须先重新查询；不自动重发SET，不自动回退参数。一次最多一个地面参数操作。并发浏览器争用同一challenge时，云存储没有CAS保证，可能只有最后一项被取走，其余请求超时；每项保留独立意图，不能将另一项的回执归给它。

浏览器状态超过3秒失效；云端心跳超过5秒拒绝新命令；请求排队最多8秒。本地用单调时钟复核剩余有效期，取本地session后、提交前再检查。已提交设备的操作可继续等其结果，这些时间限制不代表设备撤销了已提交写入。回报上传可以重试，设备命令不重试；回报长期失败后仍要求重新查询。

本地进程重启可能重用数字连接代次和操作编号，因此转发另外以地面站每次启动随机产生的session token指纹绑定实例：状态读取前后均核对本地session，提交前再核对，等待完成时也必须是同一实例。指纹和token均只留本地内存，不进入云端心跳/结果；实例改变则随机更换远端会话身份并要求重新查询。

## 本地版本与停机条件

默认B0B4保持严格版本匹配。实体B0B5必须显式加 `--xy-pi-build B0B5`，该codec来自冻结B0B5交付包，原文件哈希由地面回归测试核对。B0B5普通遥测仍可能显示B0B2，不能据此选择或认定参数能力；以所选codec取得的A591设备查询为准。

现场启动前核对实际串口和唯一接收进程；以下命令仅为操作说明，本次未执行：

```powershell
# 仓库根目录；COM实际电台串口替换为核实的端口
python -B ground/B0B4/launch.py --port COM实际电台串口 --source SiK --baud 115200 --enable-xy-pi --xy-pi-build B0B5
```

未启用 `--enable-xy-pi` 时保持只读；USB镜像只读。现有地面服务若已占用串口，先在停机维护窗口按既有流程交接，不能启动第二个串口所有者。`remote_pi.py`只访问loopback HTTP，不打开串口。

提交前人工确认拆桨、停机、未解锁、CH5低/中位、底部水上电机已停止。地面服务在发送前复查新鲜一致的遥测、控制器及命令状态、四路空中PWM等；FPGA在原子提交边沿最终裁决。B0B5额外检查水上中立且未使能。当前遥测不直接提供两路水上电机实际脉宽，不能将云状态当作对其停止的独立测量。

## 配置与启用

1. 发布本目录完整EdgeOne应用，包含 `cloud-functions`、`worker`、`platform`、构建后的 `public` 及原依赖。现有 `PUBLISH_TOKEN`继续只供发布端；新增不同的随机 `CONTROL_TOKEN`供操作者。建议32～512个可打印无空白字符，不写入仓库、URL、网页源码或日志。缺少任一密钥、太短或两者相同，所有远程参数接口均返回503关闭状态。新增密钥需由账号持有人配置。
2. 地面站按实际固件版本显式启用本地参数入口。确认本地设备查询/停机资格后，在另一终端主动启动转发：

   ```powershell
   # 仓库根目录；隐藏输入现有发布令牌，不输入网页控制密钥
   python -B web/flight-console/local/remote_pi.py --enable-remote-pi --prompt --site-url https://gmflylog.com --upstream http://127.0.0.1:8765
   ```

   发布令牌通过 `getpass` 隐藏输入，仅内存使用；没有私密控制台时拒绝回退到明文回显。供受控启动器使用的单行JSON stdin方式仍可用，字段为 `site_url`、`publish_token`、可选 `upstream`。不把令牌拼进命令参数、环境变量或临时文件。
3. 网站打开 `/parameters`，输入独立控制密钥。刷新、退出或离开该页面后密钥清除，不存浏览器storage。先点“查询设备”，确认实际读回，再编辑草稿并勾选停机确认，最后点击成对写入。默认值按钮不提交请求。每次页面连接、地面连接或结果未知后都重新查询。
4. 调参结束用Ctrl+C停止转发。此功能需要显式启动，不随地面站或实时分享自动启动；停转发后云状态自然过期。仅浏览网站不会启动本地转发。

调参期间会增加心跳、取命令及结果轮询请求，应只在维护时短时开启，仍受现有平台免费额度限制。本次没有更改收费档位或开通付费服务。

## API与数据边界

- 操作者请求使用 `X-Flight-Control-Token`，发布端使用 `X-Flight-Publish-Token`；角色不能互换。操作者POST必须同源，云API拒绝未知字段、重复JSON键、任意路径和非规定操作。
- `GET /api/remote-pi/status`、`POST /api/remote-pi/command`、`GET /api/remote-pi/result/<epoch>/<id>`供操作者；`POST heartbeat`、`GET poll`、`POST result`供地面转发。全部控制响应 `no-store`，不输出密钥、串口名或本地文件路径。
- 状态/结果仅保留批准的参数字段。转发向本地固定 `/api/xy-pi/*` 路径请求，发送本地Origin及短期session token；本地token不出机。只接受云端HTTPS；回环HTTP仅供离线测试。拒绝重定向，不能转发任意HTTP、串口指令或解锁命令。
- 云Blob的 `control/heartbeat.json`、`control/request/<epoch>/<challenge>.json`、`control/result/<epoch>/<id>.json`不进入匿名日志列表。8秒TTL控制执行资格，**不是自动删除Blob**；请求/结果会累计。清理应在转发停止、相关epoch结束后由维护者执行，保留仍活动的意图/去重记录；本次没有自动清理或删除用户数据。
