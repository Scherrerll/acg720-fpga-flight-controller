# Estimate / Setpoint 姿态跟踪显示

本次仅改地面接收、转发和网页。不修改 RTL、约束、位流或 Flash，不重新综合、布线、烧录。

## 已有遥测

B0B0 的 A579 主包已包含下列字段。目标来自 FPGA 上报，不能用遥控杆映射值替代实际控制目标。

| 网页/CSV 字段 | A579 来源 | 单位与含义 |
| --- | --- | --- |
| `roll_sp_deg` | `target_roll_cdeg / 100` | 横滚目标角，度 |
| `pitch_sp_deg` | `target_pitch_cdeg / 100` | 俯仰目标角，度 |
| `yaw_rate_sp_dps` | `target_yaw_rate_cdeg_s / 100` | 偏航目标角速度，度/秒 |
| `yaw_rate_dps` | `gz_corrected / 16.4` | 已滤波、去偏的机体 Z 轴陀螺角速度，度/秒 |

Roll/Pitch 与同一主包的姿态估计角比较。Yaw 比较的是角速度；现有包没有航向角目标，不能把角速度目标画在航向角坐标上，也不在地面端积分出一个冒充 FPGA 目标的航向角。原相对航向角仍单独保留。

目标线按阶梯绘制，缓冲回放在下一个真实目标样本到来前保持前一上报值；估计/测量线保持原平滑方式。缺失或无资格的数据保持空值，源缺口、过期提示和原始解锁/PWM 值保留。停机时上报的目标不代表控制正在生效。

## 使用

实时页分别显示 Roll、Pitch 和 Yaw Rate 的 Estimate/Setpoint 对比。日志分析新增“跟踪对比”选择框，可切换三轴，也可继续自选字段；有完整 Roll 对比字段时默认选中这一对。没有相应目标字段的旧共享日志不会补造目标。

接收器通过 `local/receiver_setpoints.py` 包装已有只读服务，在内存中增加快照与 CSV 导出字段，并在新日志元数据中记录包装器源码哈希。已有原始日志不改写；其中带有新鲜 B0B0 身份和 A579 目标字段的记录可由新版导出器重新读取。既有云日志仍使用原已分享副本，不自动重新上传。

完整仓库内可运行 `python local/receiver_setpoints.py --port COM17 --baud 115200 --source SiK --http-port 8765 --logs "原有日志目录"`，工作目录为 `web/flight-console`；先退出占用同一串口/HTTP 端口的旧接收服务。独立部署副本需另加 `--receiver-dir "原 ground_server.py 所在目录"`。HTTP 转发仍用原显式分享入口。

本机已加载包装器，并保持原 COM17/115200/SiK 配置与原日志目录。旧日志段 `20261024T025939Z_beb53bf1` 正常关闭，新段为 `20261024T091159Z_65ddb3d0`。原 `ground_server.py`、`protocol.py`、`analysis.py`、`recorder.py` 文件哈希均未变化。
