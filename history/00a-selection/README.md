# 00a：目标、架构取舍与硬件选型

根据先前会话重建的设计记录，时间为北京时间。**这里只记录当时目标和决策，不将方案参数倒写成已实现性能。** 本文于2026-10-22整理，原始聊天、购买订单、软件许可证、账号或MAC信息未上传。

## 2026-09-18：架构讨论

“FPGA无人机方案”会话在19:21～19:26讨论开放选题：核心实时控制由FPGA承担，包括传感器接口、滤波、姿态/速度等控制及电调输出；推荐以参考算法、C/Python模型、定点RTL逐步对照，避免把完整单片机固件直接套入软核当作移植完成。

这一阶段提到ACG525/GW5A、BMI088、PMW3901、VL53L1X和室内低空定点，属于候选组合。PWM/DShot、2kHz/500Hz/100Hz分层速率、更多串级环路同样只是设想。软核不是必需项，ROS仅作为可选上位机。**这些候选与后来实际ACG720工程不能混为同一配置。**

该会话最早可见回复提及更早的PicoRV32/Crazyflie讨论，但工具未返回被引用原文，故不补造其日期或最终取舍。9月22日的水空两栖、浮筒/水面推进器、GNSS/RTK、D435i、视觉和八路动力扩展也属于构想，不是本仓库的已实现功能。
