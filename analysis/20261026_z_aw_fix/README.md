# B0B4：修正高度积分饱和并设置用户选择的水平默认值

用户要求：修正最低油门时目标下降而高度总油门仍顶满的代码机制；将定点模式共享水平参数的开机默认值改为 **P=0.1000、I=0.0350**。用户要求低空掉高不再调查，本轮不改倾角补偿、高度融合或传感器处理。

新代码在 `firmware/B0B4/`，新地面站在 `ground/B0B4/`。冻结B0B3及其原证据保留。最终可交付状态以B0B4 qualification.json为准；源码、行为测试和物理时序资格分别记录，任何离线结果都不是已经装机或飞行验收的证据。

## 改了什么、为什么

旧实现允许高度I在输出已达到0..850增量上限后继续同向积累，最低油门时需要长时间退回。新实现保留原误差、积分步长和原积分rail，先暂存候选I，等本回调P及更新后的bias可用后再判断最终输出：超出上限且候选I仍增加，或低于下限且候选I仍减小时，拒绝该步；反向消积继续接受。选择后的同一个I同时提交到积分器和输出，避免非阻塞赋值误用旧I。reset/cancel丢弃未提交候选。

新增两个流水状态，Z发布比旧版增加2个50MHz时钟（40ns），PID仍按11ms计算。未饱和时按回调比较输出和内部积分等价；饱和时有意改变原P2积分行为，这是解决该机制的取舍，不宣称与原P2完全逐状态一致。低杆直接停桨、着陆判据、运行PWM上下限、降级逻辑和原安全门均未变。

参数银行的INIT和reset都改为wire1000/350，generation=0；控制器开机工作快照一致。用户后续手动SET仍是本次上电有效，重启恢复新的0.1000/0.0350；没有增加Flash参数保存协议。A591和FPGA UserCode使用B0B4；新地面站严格识别B4，并同步初始草稿、默认按钮和重启说明。旧A580公共B0B2标签保留兼容，不能据其判断新固件身份。

### 保留的首轮测试失败

`rtl_regression/results.json`保留首轮I0夹具失败：夹具把高度/XY并发输入加速到原事务无法完成的间隔。增强诊断在相同过快间隔下复现B3/B4同时overrun、reason128/128，属于原保护被夹具触发，未据此改产品源。

只为I0创建独立attempt02，把间隔2500→20000clk，保留原11000/22000us逻辑dt和全部原断言；该用例实际exit0。前4项已通过场景没有重复运行或覆盖，原失败没有改成通过。最终资格使用单独final_results.json，不能只看首轮failed汇总或只删掉失败记录。
