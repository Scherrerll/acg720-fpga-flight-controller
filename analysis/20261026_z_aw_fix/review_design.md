# Z antiwindup 最小方案只读设计复核

审阅基线：当前冻结 B3 `firmware/B0B3/source/position/mtf_xyz_hold_control.v`，SHA256 `b7eef6d33789523cd1e8ff81b05e75db91ab3c67bf76e03483dec356055fa1a6`。本文件仅为新候选设计建议；没有修改固件、旧分析或操作硬件。

## 结论与提交顺序

提议可行：保留现有数学事务、状态顺序和 11 ms 回调，把 Z I 的最终提交由 state22 延到 state24，使用本回调的 P 结果与 **state23 已提交的新 bias** 决定是否接受积分候选。无需增加除法或改变安全 mask。它修复的是已证明可达的 Z 输出高夹持后积分继续同向积累；并不等于已经验证本机物理着陆。

推荐明确使用下列 signed64 语义（全部量为 Q16；这里只是伪代码）：

```
state22:
    candidateI = taking_off ? clip(oldI + integral_step, original_lo, original_hi) : 0
    // 暂存 candidateI；此时 iz_store 仍保存 oldI。
    // 原 bias 数学请求与状态流不变。

state23:
    bias = taking_off ? old_bias + bias_step : 0
    // 原 P 数学请求不变；到 state24 时 value 是本回调 P。

state24:
    candidateSum = P + candidateI + bias
    reject = (candidateSum > 850*65536 && candidateI > oldI)
          || (candidateSum < 0         && candidateI < oldI)
    selectedI = reject ? oldI : candidateI
    iz_store = taking_off ? selectedI : 0
    collective_q16_store = taking_off ? clip(P + selectedI + bias, 0, 850*65536) : 0
```

`selectedI` 必须是同时供上述两次赋值使用的组合值/明确暂存值。不能先非阻塞写 `iz_store<=selectedI`，随后仍用 `P+iz+bias` 计算输出；后者读取旧 I，接受候选时会形成一个回调的错配。也不能拒绝 I 后继续输出 `candidateSum`。

## 必须守住的边界

1. **方向比较采用候选的实际变化。** 比较 `candidateI > oldI` / `< oldI`，而不只是 exz 或原始积分步长的符号。候选已经过原动态 rail，限幅本身也可能改变候选方向。`candidateI==oldI` 不增加积分，没有必要把它当作同向继续积累。
2. **严格越界。** 使用 `>850Q` / `<0`；恰好等于边界可以接受。边界相邻至少覆盖 Q16 的 ±1 LSB。拒绝整个步长会在边界留下不超过一个积分步长的余量，这是该条件积分策略的可预期结果，不是精确回算到边界的算法。
3. **允许反向消积。** 已在上饱和时，只要候选 I 下降，即使候选总和仍大于850，也应接受；下饱和时对称允许 I 上升。只检查“输出饱和就冻结”会保留现有记忆，不能解决下降恢复。
4. **bias 时刻与旧 rail 保持原语义。** state53 已按旧 bias 生成原 I rail，state22 用该 rail 形成候选；state24 的输出判定用 state23 的新 bias。不要顺手改成按新 bias 重新计算候选，否则普通未饱和轨迹也会变化。若要宣称保持分支每拍仍满足本拍动态 rail，需实际检查 `oldI` 也在该 rail 内；对任意私有寄存器预置不能直接假定这一点。真实自然复位轨迹中 bias/I 均从零开始，不把不可达预置组合报成产品反例。
5. **完整 signed 宽度。** 候选、旧 I、P、bias 和两次求和都显式 sign extend 到 signed64。阈值使用 `64'sd55705600` 和 `64'sd0`。不要先在窄 unsigned 拼接或窄寄存器里求和再扩展；候选存储至少保持原 I 的有符号范围。本补丁无需缩窄其他算术。
6. **复位、取消和失败所有权。** reset、cancel/origin_reset/blocked 分支继续清 I，新的候选暂存也清零；taking_off=false 时 I 和输出仍为零。任何新 Z 回调必须先经过 state22 才能在 state24 使用候选。数学错误/取消后不得把旧候选带入下一回调。state24 只提交私有状态，原 state25 发布时刻和所有 live mask 保持原样。
7. **这是 Z 模块自身的0..850增量限幅域。** 它没有读取四电机混控后的上下限/差动余量；1200us运行 floor、混控饱和仍独立存在。不得把本方案宣称为完整执行器抗饱和、掉高修复或所有合法反馈下都保证立即下降。旧 I 已经很大或误差仍未反向时，条件积分也不会主动清掉已有 I；本次正常复位后的新轨迹应阻止原来的持续同向 windup。

实现时新增一个候选暂存已足够，不需要再复制 oldI（iz_store 自身可以保持 oldI 至 state24）。若为资源原因复用已过生命周期的原临时寄存器，必须证明它在 state22 后到 state24 无其他写入、每次回调都刷新，并相应修正注释；不能仅按名称猜测可复用。

state24 会增加求和、比较和选择逻辑。源级可行不能代替现有小裕量设计的真实综合/布线/20ns全部时序表验收。可把旧/候选输出和并行计算后选择，避免把“选择 I 后再长串求和”无意串成更长路径；不因此放宽时序约束或安全门。

## 有意义且有界的真实 RTL 回归

使用真实新/旧控制器和 `nav_math_service`，合法接口刺激；私有预置仅能作为明确标注的补充边界测试，主证据从真实复位自然到达。

| 测试 | 应检查的结果 |
|---|---|
| 普通未饱和轨迹 | 从相同复位开始，整条轨迹没有 AW 拒绝时，每次 Z 发布的 collective、目标高度、爬升指令、bias/I 及发布周期与冻结旧 RTL 一致。至少有正/负小误差、bias 上升阶段、零误差。 |
| 自然上饱和与反向低杆 | 复用已保存的合法固定 height300/vz0/az0、CH3=1684自然积累→1002见证；旧 RTL 保留历史失败对照。新 RTL 上夹持期间不得继续同向增加 I，反向误差必须被接受；确认目标下降、输出实际离开高夹持，选中 I 与同回调输出严格一致。实际恢复时间单独报告，不写成飞行等待建议。 |
| 自然下饱和与反向上杆 | 从复位用合法负误差到下夹持，阻止进一步负积分；转为正误差后允许消积，即使输出暂时仍夹在0。上下两方向都检查。 |
| 数字边界 | candidateSum 为0、850Q及各自±1LSB；候选实际增量正/零/负。验证等号、signed比较和拒绝分支输出使用 oldI；接受分支输出使用 candidateI。可用独立组合判据测试补充覆盖，不能替代自然状态机测试。 |

旧/新等价只在从相同状态开始且尚未发生 AW 拒绝的轨迹上要求。发生预期 I 分歧后，不能继续以冻结旧输出作为全面等价目标；应检查上述新不变量和真实状态机参考算式。

## 新开机默认值的独立要求

用户选择的是共享 XY P=.1000/I=.0350，对应 wire `1000/350`。权威参数 bank 的 `initial` 和 `!rst_n` 默认都要一致修改，generation仍从0开始；GET/SET、范围、CRC、安全提交和易失语义保持。仅修改控制器 work_p/work_i 初值不足以改变权威 bank。控制器空闲采样应保证首个实际 XY 回调捕获1000/350；测试首个GET与首次回调，不只检查源码常量。

默认值变化与 Z antiwindup 是两个可分别验证的行为变化。未饱和 Z 等价测试应隔离 XY 输出差异；若比较完整XY回调，应给新旧相同显式参数。用户没有要求本次处理前飞掉高，本候选不扩展倾斜补偿/高度融合/传感器/落地检测器或运行PWM范围。

设计判定：无源级阻塞项；在以上提交一致性、signed边界和撤销条件落实后，适合进入独立候选的实际 RTL 及物理验收。当前尚无该新候选的测试/综合/时序通过声明。
