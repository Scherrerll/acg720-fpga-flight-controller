# 低油门不下降：Z 积分饱和的可达见证

本轮确认一个真实 RTL 可达的控制问题：Z 速度环积分上限与实际输出上限不匹配，正误差可在输出已经饱和时继续积累；随后最低油门虽使目标高度下降，旧积分仍能把推力长时间顶在上限，并阻止自动着陆计时。这与本次新实飞记录高度吻合，是首要根因候选。**实飞未记录内部 Z 积分，因此没有唯一确诊该次飞行的内部状态。** 本报告没有改固件、调参或操作硬件。

## 已观测到什么

同 epoch8、seq4259–4282 的 24 个完整观测组：CH3=1002、CH5=2000，目标高度从 +1284 降到 −1740 mm；融合高度仅 260–318 mm，Z collective 全部为 1850 us。XY/Z active、taking_off/flying 为真，fallback 为假，Z reason=0。原窗口约 4.6 秒；输入来自日志支线固定快照。见 `low_stick_excerpt.csv`、`evidence_summary.json`，原派生表 SHA256 `51d70972e3218f6d6917f6eb2ec5a6c4a0738e37f5c07235aa5cdd923a3c2086`。

因此最新投诉不是“最低杆没有传到目标高度”，也不是仅仅接地后 1200 us 怠速。此前其他低杆窗口有 1000–1195 us collective，不能把所有低杆现象混为一种原因。

## 实际源码机制

以下路径相对仓库根目录。

| 环节 | 当前 B3 代码和含义 |
|---|---|
| 杆量 | `firmware/B0B3/source/position/ano_z_stick.v:48` 起，1000–2000 杆量、50 死区、0.5 LPF，下降稳态限幅 −2500 mm/s，上升 +3500 mm/s；每 1 ms 速度变化限 ±8 mm/s。低杆符号没有反转。 |
| 消费与目标 | `position/mtf_xyz_hold_control.v:315` 捕获已完成 stick；`:417` 合成下降速度；`:420` 按 11 ms 积分；`:423` 限在**上次高度反馈±2000 mm**，没有 0 mm 硬下限；`:443` 高度误差输出限 ±1500 mm/s。 |
| 自动起飞 | 同文件 `:266`、`:405`，最大附加 +800 mm/s，最多 5 s，2 s 后明显杆量可结束。新窗口 auto_takeoff=false；全低杆 −2500 即使叠加 +800 也应为下降。 |
| Z P/I | 同文件 `:391`–`:402`：误差包括高度环、0.6 倍上次爬升指令、垂速及加速度反馈。P 为 0.2 us/(mm/s)；积分误差限 ±1000 mm/s，11 ms 每次最多变化 1.1 us，即约 100 us/s。 |
| 上限失配 | `:393` I 限幅为 ±(2000−bias) us，`:398`–`:401` bias 趋近 350 us；但 `:402` 合成输出另裁到 **0–850 us 增量**，`:449` 才加 1000 得 1000–1850 us。没有依据这个输出饱和状态停止同向 Z 积分的条件。 |
| 落地判据 | `core/ano_flight_state.v:39` 需要低杆≤1150、正常解锁、非正杆、延时到期及 **collective<1250** 连续约 1501 ms。高 collective 会每次把 landing_ms 清零。 |
| 判据实际接线 | `core/flight_core.v:423`、`:437`，判据接自动/降级选出的**混控前** collective；`:461` 的电机 1200 us 下限不在这个判据反馈通路。1200<1250，本身没有构成永久死锁。 |

稳态最低杆、固定高度/垂速/加速度反馈时，高度环最低 −1500 加 0.6×−2500，得到误差 −3000 mm/s，P 项为 **−600 us 增量**。若此前 I≈1650、bias≈350，则未夹紧输出仍约 `−600+1650+350=1400 us 增量`，超过 850。即使积分开始反向回退，也会持续高夹持；1400 是增量，不能误报为总 PWM。

这不是本次可调 XY P/I 直接改动了 Z 参数。`work_p/work_i` 用在 XY 回调；Z 系数仍为固定源码值。

## 实际 RTL 见证（已完成，未扩展场景）

`run_witness.py` 使用当前真实 B3 `mtf_xyz_hold_control`、`ano_z_stick`、`nav_math_service` 及真实乘除模块。固定合法 height=300 mm、vz=0、az=0，taking_off/enabled 为接口输入；先 CH3=1684 约 20 秒逻辑时间，让 I **从复位零值自然积累**，再 CH3=1002。没有 force、层次预置或修改 RTL。固定传感器边界不是飞行器动力学模型，也不是该次飞行逐样本重放。

| 检查 | 实际结果 |
|---|---|
| 首 4600 ms 低杆 | **419/419 次** Z 发布 collective=1850 |
| 目标首次变负 | 低杆后 1199 ms |
| 首次离开 1850 上限 | 低杆后 6182 ms |
| 首次 collective<1250 | 低杆后 12188 ms |
| 故障 | 未出现 controller blocked、stick fault 或数学错误 |
| 结束状态 | target=−1700、climb=−2500、collective=1000，说明不是永远无法退出的状态机死锁 |

**以上 6.182/12.188 秒仅属于此固定传感器见证，不是本机飞行等待时间或操作建议。** 每个回调仍携带真实 11000 us 输入时间，内部重放 11 个 1 ms stick 步骤，Z PID 仍为 11 ms；调用间隔加速为 2500 个 50 MHz 时钟，留足真实数学事务完成时间。没有用这个加速模型验证真实墙钟时序、传感器链或电机。

另一个独立真实 `ano_flight_state` 边界测试仅将公开 `TICKS_PER_MS` 设为 1：低杆+1850 经 5000 个逻辑 ms，landing_ms=0；1250 不计时；1249 经 1501 个连续合格逻辑 ms 触发 land_lock。它不仿真飞机接地，也没有强制最终 safe 输出。

两个 vvp 子进程均正常返回 0。详细原始日志、3182 行 Z 发布表及编译输入见 `rtl_results.json`、`z_trace.csv`、`inputs.json`。Z 日志 SHA256 `726949766eee136ca9a688ab564ee3c3f9eb14cd7ded7d3a0e546e54a12a9bdd`。

## 与 P2 原 C 的关系及修复边界

本地原 C 的 `SRC/fc_specific/config.h:39,74–80` 设置 FINAL_P=.35、THR_INTE_LIM=70/FINAL_P、THR_START=35；`Ano_AltCtrl.c:179–211` 的 0.6 速度前馈、积分上限减 bias、bias 相加及 850 输出限幅与上述结构一致；`fc_general/Ano_Pid.c:49–66` 为误差积分后限幅，没有输出饱和反馈。`Ano_MotorCtrl.c:86–109` 直接使用 ct_val_thr 混控，未见 Z 输出再乘 FINAL_P。因此该上限失配有原 C 来源，不能归为这次 XY 运行时接口引入的符号/量纲回归；继承原 C 也不代表这一行为可忽略。原 C 仅作源级对照，未编译执行；外部路径和原文件哈希见 `source_references.json`，未重新分发第三方源码。

最小修复方向是为 **Z 环** 建立与实际输出能力一致的抗积分饱和：输出高夹持且误差继续推高时阻止同向积累，同时允许负误差消积；积分轨迹应考虑 P、bias 和输出余量。简单降低 XY I 不解决这个固定 Z I 通路。具体实现还需独立候选、下降/落地/饱和恢复回归、资源和时序验收；本轮没有实施补丁，也没有移除安全门或提出空中拨低 SWA 的操作方案。

历史精确归因尚缺：Z I、bias、未夹紧输出、完整 11 ms 误差/爬升指令和 landing_ms。现有日志已经证实目标下降而 collective 高夹持，实际 RTL 证明此 I windup 机制可自然到达；它们共同构成强候选，仍不能反推出实飞每一内部寄存器的唯一值。前飞掉高由另一个倾斜/推力支线处理，不用本见证替代其分析。
