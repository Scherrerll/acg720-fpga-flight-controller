## 已复现的高度积分饱和机制

B3 高度输出为 `1000 + clip(0.2*e + I + bias, 0, 850)`。bias 趋近350；I限幅却允许约 `±(2000−bias)`，没有随最终850上限停止正向积累的反馈。I每11ms最多变化1.1，即最大约100单位/秒。

因此，较长正高度误差能在输出已到1850后继续累积I。随后最低油门稳态请求约−2500mm/s，外环约−1500mm/s，加速度和实测垂速接近零时P项约−600。若先前I+bias接近2000，减掉600仍大于850，输出会继续顶满，直到积分退回。水平P/I接口并不直接修改这个Z积分器。

真实 B3 `mtf_xyz_hold_control`、Z杆处理和数学服务的定向 RTL 测试已通过：合法固定 height=300mm、vz=0、az=0；CH3=1684自然累积约20秒后改为1002，无强制私有状态。下降后目标在1.199秒转负，但前4.6秒的419/419次Z发布仍为1850；6.182秒才离开上限，12.188秒才低于1250。独立 `ano_flight_state` 测试也通过：低杆+1850不能启动着陆计时；1250不满足严格小于判据；1249持续1501逻辑毫秒才触发land_lock。

这些时间是**固定传感器定向测试的逻辑时间，不是飞行操作等待时间**。回调的墙钟间隔加速，内部1ms杆处理和11ms PID步长保留；未模拟机体、ESC、传感器闭环、四客户竞争或整机PWM。因此证明的是源码机制自然可达，不能声称完整重放了本次飞行。日志没有内部I值，历史事件的唯一根因仍未确定；该机制是有实测对应和RTL见证支持的首要候选。

P2参考也包含该积分上限与最终输出裁剪结构。FINAL_P=0.35作用于姿态率环输出，P2高度输出并未在末端再乘一次0.35；不能以‘漏乘0.35’为由直接更改B3。

## 前飞掉高的判断边界

本节记录用户要求暂缓之前已完成的检查，不继续安排掉高调查、补偿修改或飞行验证。

当前主链没有按实际roll/pitch显式加入总推力倾角前馈。总推力不变时，其垂直分量随倾角减小，这是可能的贡献；测距几何中的余弦投影并不是推力补偿。混控逐电机裁剪，1850总油门附近上侧差动余量只有150，姿态修正可能进一步受限。

上述前飞片段实测roll仅−0.70..0.67°、pitch−1.06..3.95°，对应垂直投影损失小于0.25%，不足以直接把全部掉高归因于倾角。该片段同组上报的command和physical四PWM各自均值均为1850，均未触2000；两种四元组存在不同锁存时刻，不能据此说它们来自同次混控瞬间。最后一次飞行seq4041–4282的242个A582也都报告1850，高端状态早于最低油门。不能把PWM直接当推力，也不能由内部测距独立证明世界坐标高度。倾角、混控与参考源码细节见 tilt/FINDINGS.md。
