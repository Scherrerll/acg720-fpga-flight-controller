# 接线与单位

以下接线以 **FPGA 球位号**和选用的 CST 为准。早期关于 P7 物理针脚的描述有误，不应继续沿用。电源和公共地不在 FPGA 信号端口清单内，请使用实际板卡上的电源和 GND 标识，不要将普通 IO 用作电源。

| 信号 | FPGA 球位 | 说明 |
|---|---|---|
| clk50 | Y18 | 50 MHz |
| BMI088 SCK / MOSI / MISO | E17 / C20 / D19 | SPI |
| BMI088 加速度 CS / 陀螺 CS | E18 / F20 | 独立片选 |
| PPM 输入 | B17 | 当前遥控通道配置 |
| 有线 UART TX | M15 | 只读遥测输出 |
| LED2 / LED3 | L21 / K21 | 状态灯 |
| M1 / M2 / M3 / M4 | D17 / C17 / E16 / D16 | 电调 PWM |
| MTF TX → FPGA RX | C14 | Micolink 115200 |
| MTF RX ← FPGA TX | C15 | 当前接线保留，不要当作供电脚 |
| SiK RX ← FPGA TX | B15 | 单向下传 |

## MTF-01P 与数传

MTF-01P 的模块供电和 TTL 信号电平需要分开考虑。本项目使用 5 V 供电、3.3 V UART，并与 FPGA 共地，通信为 Micolink / 115200。安装按用户选择的右图方向旋转 180°；当前坐标映射为机头前向 `rawY`、机身右向 `-rawX`。模块和 FPGA 两处不要重复配置旋转。旧 PMW3901 和独立测距接口保留在历史源码中，不是当前 MTF 的主数据源。

机载 SiK 的 TX 信号线曾接到 B16，但本候选仅声明并使用 B15 下传，没有供地面控制飞机的上行命令接口。电脑端波特率需要与电台实际串口配置一致。

## 电机与遥控器

从上往下、站在机尾看向机头：M1 左前 CW，M2 右前 CCW，M3 右后 CW，M4 左后 CCW。这是此前的核对结果，变更接线或电机后仍需重新检查。

遥控配置记录为 CH5=SWA、CH7=SWC。SWA 用于停机和解锁，SWC 用于请求模式；网页中的请求状态与控制实际启用状态是两个不同的字段。

## 数据单位

MTF 距离以 mm 进入几何链路；机体和导航内部速度、时间按各接口的命名进行转换。原始 MTF `vx_x100/vy_x100` 应保留字段比例后再转换，不能将整数位宽直接当作小数位。偏航沿用 Q12/Q24 运算和相对角度，不应加入未经验证的比例缩放。

## 已记录的硬件配置

用户报告的整机重量约 2.35 kg，曾使用 3S 3300 mAh/45C 和 4S 2300 mAh/45C 电池；电调直接连接电池或分电板，FPGA 通过原 12 V 升降压模块供电。这些是实物配置记录，不代表供电带载已经通过验收。
