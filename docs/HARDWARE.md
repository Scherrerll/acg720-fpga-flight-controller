# 当前候选接线与单位

以下以 **FPGA 球位号**和选用 CST 为准，避免沿用早期对 P7 物理针脚的错误描述。电源和公共地不在 FPGA 信号端口清单内，应使用实际板卡电源/GND 标识，不将普通 IO 当电源。

| 信号 | FPGA 球位 | 说明 |
|---|---|---|
| clk50 | Y18 | 50 MHz |
| BMI088 SCK / MOSI / MISO | E17 / C20 / D19 | SPI |
| BMI088 加速度 CS / 陀螺 CS | E18 / F20 | 独立片选 |
| PPM 输入 | B17 | 当前遥控通道配置 |
| 有线 UART TX | M15 | 只读遥测输出 |
| LED2 / LED3 | L21 / K21 | 状态灯 |
| M1 / M2 / M3 / M4 | D17 / C17 / E16 / D16 | 电调 PWM |
| MTF TX → FPGA RX | C14 | Micolink 115200 |
| MTF RX ← FPGA TX | C15 | 当前接线保留；不要当作供电脚 |
| SiK RX ← FPGA TX | B15 | 单向下传 |

MTF-01P：实际模块供电与 TTL 电平分开考虑；本项目配置为 5 V 供电、3.3 V UART、共地，Micolink/115200。安装按用户选择的右图方向旋转 180°，当前坐标映射为机头前向 `rawY`、机身右向 `-rawX`。不要在模块和 FPGA 两处重复旋转配置。旧 PMW3901 与旧独立测距接口保留于历史源码，不是当前 MTF 主数据源。

机载 SiK 的 TX 信号线曾接 B16，但本候选仅声明/使用 B15 下传，没有可供地面控制飞机的上行命令接口。电脑端波特率需与电台实际串口配置一致。

从上往下、站在机尾看向机头：M1 左前 CW，M2 右前 CCW，M3 右后 CW，M4 左后 CCW。该表记录此前核对结果，不代替每次变更接线/电机后的实际检查。

遥控配置记录为 CH5=SWA、CH7=SWC。SWA 是停机/解锁开关，SWC 是模式请求；网页的请求状态与控制实际启用状态是不同字段。

单位：MTF 距离进入几何链为 mm；机体/导航内部速度与时间按各接口命名转换；原始 MTF `vx_x100/vy_x100` 保留字段比例后再转换，不得将整数位宽直接当小数位。偏航使用既有 Q12/Q24 运算及相对角度，不能新增未经验证的比例缩放。

用户报告硬件：整机约 2.35 kg；曾用 3S 3300 mAh/45C 和 4S 2300 mAh/45C；电调直接接电池/分电板，FPGA 经过原 12 V 升降压模块。这些是实物配置记录，不是供电带载合格证明。
