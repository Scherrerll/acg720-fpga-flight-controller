# 控制边界与剩余验收（2026-10-24）

已通过：零未通与 51.608 MHz 时序；选中源码/网表/位流哈希；三个增量证明及 13 项 MTF 边界检查；拆桨正常高度控制、测距失效手动接管和重连不抢回；一分钟融合静止观察；四向带动力修正方向；Flash 编程、独立校验、重载与电池冷启动。

SWC 低/中档是自稳加高度控制，高档请求光流速度控制加高度。低档不能称作直接手动 PWM。测距失效时改用手动油门并锁存，传感器恢复不自动抢回；最低油门持续后约 1.7 s 落地锁定由操作者接受为预期行为。

水平采用融合速度 PI，没有绝对位置外部基准。累计位置用于诊断，一分钟观察 4.401 mm 不代表所有表面和动作均具备同等漂移；不同条件下的较大漂移记录一并保留。几何链路未因手动倾斜观察而新增经验比例或陀螺补偿。

仍未闭环：带桨振动/负载、空中稳定性、光流转动分量与真正平移的严格区分，以及活动 XY 控制下的实际动态表现。四向纠偏试验处于 SWC 低档且存在混控饱和，只验收方向，不评价空中增益。`flight_ready=false`。

此前约 10 s 掉动力的原因由操作者确认为电池松动；这是操作者提供的硬件说明，软件不能独立证明。没有电池电压、电流或 ESC 转速遥测；上报 PWM 不等于外部波形/推力/RPM 实测。SiK 断连期间没有机载持久日志补回能力。
