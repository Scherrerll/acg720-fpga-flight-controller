# 在地面站操作 XY 速度 P/I

已有线协议和 CLI，本次增加独立 B0B3 地面站页面。X/Y 共用一对参数，默认 P=0.05、I=0；范围各为0～1、步长0.0001。参数**仅本次上电有效**，不保存 Flash。

本次工作台已于2026-10-26 08:30（北京时间）获授权下载 B0B3 到 SRAM，08:32 完成默认参数的 SET ACK 与独立 GET 验证，generation=1。随后用户在页面手动设置 P=0.0750、I=0，ACK及独立读回成功，generation=2；未写 Flash。[实机与离线验证记录](../validation/20261026_xy_pi_ground/README.md)。这证明地面参数事务，不代表该增益的飞行效果通过；重新上电会重新加载原 Flash 镜像，需重新确认参数功能。

## 1. 准备与启动

机载需安装支持 A590/A591 的 [B0B3 参数固件](../firmware/B0B3/README.md)。新镜像仍须当次接线、拆桨停机确认及 SRAM 授权；开发本功能没有自动下载或写参数。旧 P005/I0 镜像不能通过网页升级成可调参数版本。

电台接线：FPGA B15/P7-19 TX → 机载 SiK RX，B16/P7-20 RX ← SiK TX，3.3V TTL、共地，115200 8N1。当前实体接线须由操作者核对。USB M15 为遥测镜像，不提供本调参接收通路。

在仓库根目录运行，替换实际电台 COM 号：

```powershell
$env:PYTHONUTF8='1'
python -m pip install -r ground/requirements.txt
python -B ground/B0B3/launch.py --port COM实际电台串口 --source SiK --baud 115200 --enable-xy-pi
```

打开 `http://127.0.0.1:8765/`。若旧接收器占用串口，在维护窗口由操作者释放它；不要同时开 CLI 或另一个接收器。新站共用一个串口线程完成接收与参数发送，继续本地记录日志。

安全预览（不枚举、不打开串口）：

```powershell
python -B ground/B0B3/launch.py --no-serial --enable-xy-pi --http-port 8873
```

打开 `http://127.0.0.1:8873/`。预览没有真实值，写入不可用；真实连接需退出预览后按前一条命令明确启动。

## 2. 页面步骤

1. 找到“共享 XY 速度 P/I”，点击“查询设备参数”。设备回读区应出现 P、I、generation 与 B0B3 功能标识。主遥测保留 B0B2 标签以兼容旧解析，不能单凭顶部标签判断参数固件已安装。
2. 维护时拆桨、停机，保持 CH5 低/中位。等待同组新鲜主帧及起飞状态；未解锁、控制和有效电机命令关闭，四路实际上报 PWM 均为1000μs。页面预检不是实体安全证明，FPGA在实际提交边沿再次检查。
3. 输入一对值，例如默认 `0.0500 / 0.0000`。输入框是草稿；设备回读区才是最近一次已收到的值。数值范围是编码边界，不代表整个范围都已获得飞行增益资格。
4. 勾选停机确认，点击成对写入。界面会经过发送、等待ACK、独立GET回读；只有完整P/I和generation匹配才显示验证完成。
5. “填入默认草稿”只修改输入，不发命令。恢复默认仍需确认后成对写入；重新上电也会恢复默认。

## 3. 状态与异常

| 显示 | 操作 |
|---|---|
| 未确认 B0B3 功能 | 先查询。无回复时检查镜像、电台双向接线、串口和占用；不能仅凭超时断定旧固件。 |
| 未连接／USB只读／入口未启用 | 使用正确的SiK 115200连接及 `--enable-xy-pi`；USB仅保留监控。 |
| 停机预检失败／LOCKED | 查看具体原因，保持CH5低/中、解除运行状态，再显式操作。最终拒绝以FPGA回复为准。 |
| 正在处理 | 一次只处理一笔，不重复点击；同一请求ID的重复提交不会再次发SET。 |
| 结果未知／超时／回读不匹配 | 可能已生效，绝不自动重发SET。恢复链路后先查询实际值，再决定下一笔。 |
| STALE_SEQUENCE | 可能另一工具用过更大序号；不自动重试。可在明确停机后重新上电、恢复默认并查询，勿在运行中为此断电。 |
| 断线／换端口／检测到重启 | 原会话及能力确认失效；旧请求不迁移到新设备，重新查询。 |

网页不能绕过FPGA的停机门禁，没有遥控/电机命令或Flash保存接口。GET可在飞行中查询，SET仍仅停机使用。

## 4. CLI 仍然可用

退出占用串口的地面站后，维护窗口内可用原工具：

```powershell
python -B firmware/B0B3/xy_pi_cli.py --port COM实际电台串口 get
python -B firmware/B0B3/xy_pi_cli.py --port COM实际电台串口 set --p 0.05 --i 0
```

不要和地面站同时打开相同串口。CLI及网页都要求ACK后独立GET确认，都不自动重发SET。原始协议见 [PROTOCOL.md](../firmware/B0B3/PROTOCOL.md)。
