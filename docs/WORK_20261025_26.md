## 为更好布线做了哪些改变

1. **减少重复响应存储。** TX 直接发送参数模块持有的冻结响应，参数模块也不再复制整帧。两次独立综合相对各自上一版分别减少 199FF/617LUT、126FF/136LUT；完整旧遥测 644 字节和混合流 692 字节保持一致，ready 仍等最后一个 UART 字节真正完成。
2. **分散快照使能。** 把完整 16 位工作 P/I 以及两个 27 位积分回滚快照移到 `state==0` 采样。XY 接纳的同一边沿仍捕获相同值，活跃工作期间冻结；取消时恢复相同积分。原回调快照 CE 从 215 负载恢复到 129；另一个闲置采样网为 86 个 CE、146 个总直接负载。
3. **保留已证实的物理约束。** 恢复已安装基线使用的 observer reset 全局资源指令；新增 RX 异步例外仅止于第一级同步器 D，后续路径仍计时。20ns 是原任务明确要求的实际 50MHz 目标，旧 19.5ns 报告未改写。
4. **固定网表再比较物理算法。** 同一份 `4497e28…` 网表在 P3 快速路由留下 1 根网络；P3 默认路由完整完成。没有重复相同输入冒充新尝试，也没有把那 1 根网络指认为某条未经识别的信号。

快照调整是 RTL 结构优化，包含明确的私有状态差异：闲置/复位期间的私有快照可以不同。两份真实参考控制器的 **450 个公开位、1,002,843 周期**比较一致，并覆盖两次非零部分积分的真实取消回滚；数值、安全 13 项及四客户端争用回归通过。这不是完整综合网表形式等价或实机飞行证明。

## 明确做了哪些取舍

- 参数掉电恢复 .05/0，不做 Flash 保存。
- 协议一次处理一条在途请求，处理/持包时忽略额外请求；避免覆盖 ACK 和正在提交的事务。
- 可变乘数和原积分路径需要少量额外数学步骤。实测孤立 XY 最长 101.64us，四客户端持续争用下请求至发布最长 355.84us；与独占服务输出一致。这是所测时序边界，不是飞机动态辨识。
- 保留既有保护和积分位宽，没有为了布线删 I、缩小合法增益范围或降低实际 50MHz 时钟。
- 最终没有采用一拍延迟 UART 复位、独立通信复位、串行 CRC、body-only 请求或计数器缩位实验。body-only 虽减本地 FF，却使整机多 620LUT，已停止；计数器版功能/资源通过，但父版本已完成验收，未合并其未完成的物理尝试。

## 问题分析、是否及时修改

| 问题 | 结论与处理 |
|---|---|
| 大 P 时限幅前中间值溢出 | 确认的实现问题；交付前将 P+I+FF 中间量从 signed32 改为 signed36，并用最大合法 P/速度边界验证。它不是已证明的旧振荡首因。 |
| 解锁 FF 同拍更新可能漏拦 SET | 确认的实现竞态；加入 CH5 解锁意图门和提交边沿复查，真实顶层同沿 arm/commit 拒绝测试通过。 |
| 延迟 UART 复位会丢启动跨界请求 | 实验中发现反例，立即停止该方案；最终保留原启动时刻。未把有已知反例的版本装机。 |
| 速度外环是否真正接管 | 所查当前 46/46 活动帧的实际目标与导航目标一致，可排除该范围内仅 shadow 输出的解释。 |
| 表面影响光流观测 | 同一镜像静态对照有直接证据：Y 峰值约 984.4 与 45.6mm/s。未形成通用质量阈值，未以改 P/I 冒充传感器修复。 |
| 转动相关伪速度 | V15 两段有强相关及 P2/RTL 功能差异支持；真实平移、模块内部补偿、曝光/传输时序仍混杂。没有加入未经辨识的补偿系数。 |
| 两次 XY 退出伴高度降级 | 降级锁存已确认，首次高度资格撤销的触发源仍未知。未删除保护，未声称已修复。 |
| 旧 B0B0 合法变化拒收重演 | B0B2 已移除该策略，所查窗口拒收累计为 0；可排除这一可见机制重演，不能扩大成所有 IMU/高度问题均排除。 |

已确认且属于本次实现范围的缺陷在交付前修复并回归。仍属假设或需要实物辨识的问题保留为未决项，没有静默扩大成控制算法重写。回中刹停和持续悬停仍未获得新镜像实测验收。
