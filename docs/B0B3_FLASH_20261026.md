# B0B3 长期调参入口

2026-10-26，经用户明确选择长期保留，已将先前 SRAM 实测通过的同一份 B0B3 镜像写入外部 Flash。擦写随附校验、独立 Flash 校验、重载后的 JTAG 身份和无线参数查询均已通过；实际断电启动验证另见[本次记录](../validation/20261026_b0b3_flash/README.md)。

- 以后上电从 Flash 自动加载 B0B3，使用调参入口无需再次下载 SRAM。
- P/I 数值仍仅本次上电有效。重启恢复 P=0.0500、I=0.0000、generation=0；之前设置的P=0.0750不会自动保存。
- 地面站保持运行时，重新上电后点击“查询设备”；确认设备回读出现B0B3及实际P/I后，再按拆桨停机步骤编辑并成对写入。顶部主遥测的B0B2兼容标签不代表已退回旧固件。
- 当前服务地址为 `http://127.0.0.1:8765/`。从仓库根目录重新启动时，仍使用 `python -B ground/B0B3/launch.py --port COM实际电台串口 --source SiK --baud 115200 --enable-xy-pi`，串口号按当次设备核对。详细页面步骤见[调参操作说明](XY_PI_GROUND_STATION.md)。

固化 Flash 改变的是上电加载来源；所用FS SHA256仍为 `a5b893b25a5e510348c8a4ac75c914b8a14473bbfb054b4cc4040b86800f64dd`，与先前SRAM实测逐字节相同。因此配置完成后的B0B3运行逻辑相同，没有在固化时追加控制算法改动。

相对旧P005固件仍存在此前已经说明的差异：新增运行时共享XY P/I、停机原子写入门禁和参数响应；非零I路径恢复，并修正合法大P的中间结果溢出；共享数学步骤增加微秒级完成延迟。默认P=.05/I=0的数值对照已通过，前馈、加速度反馈、高度环、姿态/角速度环、混控、原保护和原角度限幅保持。固化与台架通过不代表新的飞行效果已验收。

原P005/I0回退镜像仍保留在 `firmware/B0B3/release/current_P005_I0.fs`，SHA256 `a876c8ed073588e17b6289f8aac7573334a5d5e9c992d394d0d14f61ed17db7c`。现在Flash已经更新，单纯断电不会再回到P005；如需回退，须按明确授权的维护流程重新烧录并验证。
