# B0B4 / 显式 B0B5 地面站：共享 XY 速度 P/I

本目录来自冻结B0B3地面站的新副本，保留B0B2 v3遥测接收、自动日志及同一个串口所有者。参数能力默认仅接受A591中的B0B4标识；2026-10-31新增显式 `--xy-pi-build B0B5`，使用独立冻结codec并只接受B0B5，两个版本互相拒绝。旧A580遥测继续显示B0B2，不能据此认定参数能力。B0B3原地面站、固件及历史验收记录未修改，provenance/仅描述复制种子，不是本目录修改后的验收清单。

新候选的开机默认值为 **共享水平XY速度 P=0.1000 / I=0.0350**（wire1000/350），generation从0开始。这不是高度Z增益，也不是落地控制修复本身。参数只在本次上电有效；重启恢复这对新默认值，网页不会自动写参数或保存Flash。该目录不自动安装固件，B0B4的构建、物理实现和安装资格另由对应固件交付记录确认；本目录的离线软件测试不构成硬件或飞行验收。

## 本地界面改版（2026-10-30）

本目录的实时监控、日志页及参数帮助已采用 GM-FLY 官网视觉。P/I 已移到独立的 `/parameters` 页面，在左侧“日志分析”下点击“P/I 调节”进入；实时页不再包含参数卡片。B0B0 只读版、B0B3 及 ground 根目录版本均保留。2026-10-30界面改版当时尚不支持B0B5参数；**2026-10-31已基于B0B5冻结交付包新增显式选择，仍须设备实际查询通过才有写入资格**。当前代码与离线验证不等于该功能已完成硬件验收。

[变更、实测截图与验证记录](UI_REDESIGN_20261030.md)。可用临时合成数据预览（默认端口由系统分配，所有 POST 拒绝，不打开/枚举串口）：

```powershell
python -B ground/B0B4/preview_ui.py --http-port 0
```

脚本输出实际本机 URL；`/__preview?scenario=live` 切换实时样例，其他场景及验证命令见记录。常规 `launch.py --no-serial` 仍显示真实无数据状态，不注入演示数据。

## 一键打开本地地面站

双击本目录的 `启动本地地面站.cmd`，或运行 `python -B ground/B0B4/open_local.py`。入口优先复用 8765 或 8874 上接口兼容的本地地面站，再打开其 `/parameters` 页面；本地页面不需要网站远程控制密钥。

如果没有已有服务，入口在 8874 创建无串口预览，并显式选择 B0B5 参数版本；它不打开串口、不启用参数写入，也不填充演示遥测。已有实例的固件选择和写入配置保持不变。数据接收及实际调参仍按下方的实际串口启动说明配置。

`--no-browser` 只准备服务；`--port` 可指定空闲预览端口。8766 属于网站 HTTP 旁路，入口不使用该端口。

## 启动与操作

仓库根目录，Python3.10+与pyserial：

```powershell
python -B ground/B0B4/launch.py --port COM实际电台串口 --source SiK --baud 115200 --enable-xy-pi
```

若实体固件为B0B5，必须另加 `--xy-pi-build B0B5`。B0B5 codec逐字节复制自 `analysis/20261028_water_drive/qualified_offline_B0B5/xy_pi_cli.py`，SHA-256为 `869a061525ea11e25288acd187b61d848a12ebd2b51e2235f549e11699ef12b0`。没有按普通遥测标签自动猜测版本，也没有通过放宽B0B4校验接受B0B5。

页面为http://127.0.0.1:8765/，运行记录默认写入忽略目录ground/runtime/B0B4。自行核对实际串口；已有接收器占用时在停机维护窗口释放，不启动第二个所有者争用同一端口。新地面站不会关闭或替换旧服务。

仅预览页面、不接串口：

```powershell
python -B ground/B0B4/launch.py --no-serial --enable-xy-pi --http-port 8874
```

预览没有演示遥测，不枚举/打开串口，也不能通过页面切换到真实设备。未显式启用--enable-xy-pi时仅接收；USB镜像始终只读。在线参数通路仅支持SiK115200。操作说明在页面/pi-help中。

- 查询取得所选B0B4/B0B5设备的实际P/I及generation；初始输入框只是草稿，不同版本响应不能取得写入资格。
- 默认值按钮仅把0.1000/0.0350填入输入框，不发送POST/SET；草稿不会被状态轮询覆盖。
- 范围各0～1、步长0.0001；没有自动舍入。编码范围不是全范围飞行资格。
- 写入前确认拆桨、停机、底部水上电机已停止、未解锁且CH5低/中位；后端发送前再次检查，FPGA在实际原子提交边沿最终裁决。B0B5还在FPGA中检查水上中立且未使能，地面遥测没有直接报告两个水上电机的实际脉宽。
- SET保持忙碌直到ACK后的独立GET验证完整P/I和generation。超时、断线或不匹配先显式查询；不自动重发SET，也不把默认值当成失败回退写入。
- 一次仅一个在途操作；换连接/检测重启后旧会话失效。token仅本地会话接口使用，不进入公开遥测、日志或分享。

官网远程参数页的代码、独立密钥及本地主动转发用法见 [远程参数接入说明](../../web/flight-console/REMOTE_PI_20261031.md)。只启动本地地面站不会开启公网参数转发。
