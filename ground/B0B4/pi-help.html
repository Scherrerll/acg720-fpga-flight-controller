共享 XY 速度 P/I 操作说明

先确认接口可用

接收服务默认选择 B0B4 参数协议。使用已核对的 B0B5 版本时，启动参数需明确增加 --xy-pi-build B0B5，并按原流程启用参数入口；选择 B0B4 时拒绝 B0B5 回复，选择 B0B5 时也拒绝 B0B4 回复。B0B5 软件接入已有离线协议验证，实际无线读写与飞行表现仍需单独实测；页面不会下载固件。旧 P005/I0 固件不支持该接口。电台接收使用 115200 baud，参数收发使用 SiK 无线串口；USB 遥测镜像只读。

普通遥测可能仍显示 B0B2，这是兼容设计。只有显式查询并收到与接收服务选定版本一致的本次参数回复，才能确认调参功能；不能用普通遥测标签代替参数查询。

页面操作

  1. 点击左侧“P/I 调节”，打开“共享 XY 速度 P/I”卡片，点击“查询设备参数”。设备回读区应出现 P、I、参数版本及选定的 B0B4 或 B0B5 功能标识；输入框中的初始值只是草稿。
  2. 维护时拆桨、停机，保持 CH5 低/中位。等待主帧和起飞状态同组、新鲜，未解锁、控制/有效命令关闭，四路飞行 PWM 均为 1000μs。B0B5 还需确认底部水上动力已停止；现有遥测未包含水上两路的实际 PWM，四路飞行 PWM 不能证明水上动力停止。页面预检不能替代实体确认，FPGA 会在提交边沿检查水上未使能且输出中位及原停机条件。
  3. 输入一对 P/I，范围各为 0～1、步长 0.0001。X/Y 两轴共用；默认 P=0.1000、I=0.0350。范围是编码边界，不代表全范围飞行增益均已验收。
  4. 勾选停机确认，点击成对写入。地面站先等 SET ACK，再自动发独立 GET，只有回读 P/I 和参数版本匹配才显示验证完成。
  5. “填入默认草稿”只改输入框，不发送命令。需要恢复默认时仍需确认并成对写入。

超时或被拒绝

  • 锁定/停机预检失败：参数未获成功确认，先处理显示的原因。不要通过重复点击绕过保护。
  • 结果未知、断线或回读不匹配：可能已经写入，界面不会自动重发 SET。恢复连接后先查询实际值，再决定下一次操作。
  • 旧序号：可能有另一工具发送过更大序号。禁止自动重试；可在明确停机后重新上电并重新查询，上电会恢复默认参数。
  • 未收到选定版本的参数回复：检查明确选择的版本、机载固件、电台双向接线及正确串口。没有回复不能区分固件与接线或链路问题。

参数仅本次上电有效；重启恢复共享 XY 速度 P=0.1000/I=0.0350，generation 从0开始。 这是水平参数，不是高度 Z 增益。本接口不保存 Flash，不控制遥控或电机。新的回中刹停、悬停和飞行效果仍需单独实测。
