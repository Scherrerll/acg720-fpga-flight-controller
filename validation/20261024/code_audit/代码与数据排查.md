# B0B0 代码与数据排查

本轮检查未确认出需要修改的新代码故障。检查对象是已上板的冻结 B0B0 版本；本轮没有改动固件、重新编译布线、下载或操作电机。

## 操作者已确认的行为

- 此前带桨掉动力：操作者确认电池松动，本轮不再把该现象列为待排查的软件故障。这是操作者提供的原因，并非软件能够独立核验的结论。
- 测距失效接管后持续最低油门触发落地锁定：操作者确认是预期行为，保留现有逻辑。单模块离线复现记录保存在 `low_throttle_repro.log`，不列为待修复项。

落地判定本身要求 CH3≤1150、总油门<1250 μs、正向杆延迟结束并持续约 1.5 秒；约 1.7 秒的复现使用总油门已为 1200 μs 的条件。实际从较高油门缓降时，触发时间还取决于接管斜率。

## 代码检查范围与结论

冻结清单包含 44 份 Verilog 文件及配套约束、头文件等共 51 份源输入。本轮针对实际参与控制的接收、几何转换、融合、状态机、接管和电机输出路径做重点审阅；没有声称完成全设计形式化证明或逐项消除全部综合警告。

| 路径 | 核对结果 |
|---|---|
| Micolink 接收与提交 | 完整校验后才提交报文；解析提交和度量提交分开一拍，避免新旧元组混合。 |
| 重复、超时与重启 | 相同模块时间戳不能刷新源年龄；丢失时撤销有效性；时间倒退清空积分纪元。正常 32 位时间及 8 位序号回绕能够连续处理。 |
| 数值范围 | 复测有符号 16 位速度极值乘以 12000 mm，正负号与乘积均正确；非法距离和状态不能变成有效数据。实际控制几何的距离范围另限制为 10–5000 mm。 |
| 坐标与单位 | 当前安装采用 forward=rawY、right=-rawX；按原生工厂速度量纲与距离换算，没有加入经验距离偏置或缩放。 |
| 控制更新 | 加速度、光流和遥控更新具有独立入口；光流失效不会直接冻结手动杆采样。XY 当前为 ANO 速度 PI；位置积分主要用于显示，不是回到固定坐标的外环。 |
| 门控与恢复 | SWA、RC、IMU 和姿态健康条件参与实时输出有效性；撤销解锁后，开关一直留高不能自动重新解锁。测距恢复不会解除已锁存的手动接管。 |
| 混控与 PWM | 四路命令同拍提交、帧边界统一锁存；逐电机范围为 1000–2000 μs，接管总油门范围为 1200–1850 μs，两种限幅作用不同。 |
| 综合警告 | 检视了截位、未连接诊断端口、未使用位置外环寄存器、循环声明和被优化模块等类别；没有据此确认新故障。203 条截位警告并未被宣称全部形式化证明无风险。 |

## 新增离线验证

`reader_boundaries.v` 直接编译冻结的 `sensor/mtf01p_reader.v`，13 项检查全部通过：

1. 有效距离上界与速度极值接收。
2. 正负极值乘积精度。
3. 距离越界拒绝。
4. TOF 状态无效撤销数据。
5. 光流质量为零只撤销光流。
6. 光流状态无效保留测距。
7. 坏校验不能发布数据。
8. 下一有效包恢复解析。
9. 连续重复时间戳仍会超时。
10. 重复计数正确。
11. 新时间戳恢复时不跨旧间隙积分。
12. 时间戳及序号回绕连续。
13. 时间倒退建立新积分纪元。

测试使用 1 MHz 仿真时钟及接收器计算得到的每位 9 拍，用于加速模块逻辑验证；不构成 50 MHz 板上 UART 波形或全顶层等价证明。首次测试台把 `dist` 用作标识符，触发 SystemVerilog 关键字语法错误；仅测试台改为 `mm` 后通过，原始失败记录保留在 `reader_boundaries_initial_harness_failure.json`。固件源未改。

结果与源码、测试台、执行器 SHA256 绑定在 `reader_boundaries_result.json`；可运行 `run_reader_boundaries.py` 重现。

## 最新停机数据观察

通过只读 HTTP 接口采集 31 个快照，覆盖 FPGA 运行时间 6.4 秒：

- 均为 B0B0，遥测、IMU、测距和融合持续有效；新增 640 个模块报文，源年龄最大 7 ms。
- 模块校验、长度、UART、超时、丢包、重复及重启计数增量均为 0。
- IMU 拒收、控制器故障、门控中断和撤销计数增量均为 0；主机新校验错误和序号缺口均为 0。
- 全程未解锁、控制及物理输出未激活，四路命令和上报有效 PWM 均为 1000 μs。

原始快照为 `stopped_monitor.jsonl`，汇总为 `stopped_monitor_summary.json`。这些是 FPGA 遥测快照，不是外部示波器或转速实测。

## 仍需区分的验证边界

光流旋转分量仍未完成资格验证。`sensor/mtf_shared_geometry.v` 不接收角速度，`rotation_compensated` 固定为 0；现有转换完成单位、安装轴向及偏航坐标变换，不额外扣除镜头旋转造成的视流。厂家公开的[协议说明](https://micoair.com/docs/decoding-micolink-messages-from-mtf-01/)给出了工厂速度量纲，但不足以判定当前模块固件是否已在内部处理旋转分量。因此此项保留为待验证语义，没有直接认定故障或擅自添加补偿。

本轮不会把“未发现新的可复现故障”扩大为整机飞行保证。原布线结果仍为零未连通、51.608 MHz，setup/hold 无违例；当前只写过 SRAM，Flash 保持 B0AC，断电会回到 B0AC。带负载及试飞验收仍未完成。
