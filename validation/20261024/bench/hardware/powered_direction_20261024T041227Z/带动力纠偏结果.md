## 记录与筛选

从现有只读 USB 日志截取 6299 条分帧记录；1049 个主快照中 577 个控制器运行，首末运行快照跨度 115.198 秒，采样间隔约 200 ms。实际操作超过原定短流程，不能据此判断空中 PID 增益。

沿用 start.json 中开始前已写明的条件：右杆和偏航杆回中、SWC 低档、目标与反馈角差至少 2°、对应轴陀螺仪绝对值不超过 33 计数。表内不同轴的样本可能重叠。

## 连续性与停机

全段 B0B0 标识及运行时间连续。姿态、传感器健康标志始终有效；控制器故障计数和门控中断计数均无新增。IMU 拒收样本计数增加 4，未触发姿态无效或控制故障。

MTF 新增 20959 个报文；UART、校验、长度、超时、重启及积分断点计数均无新增。1050 份原始 MTF 载荷独立核对时间、距离、流量、有符号字节序及原厂尺度换算，全部相符。高度和融合速度持续就绪，未进入测距失效接管。最终唯一新增解锁撤销为 0x34（52）：已解锁阶段 SWA 离开高档，与人工停机一致。

## 适用范围

运行快照中 326 点出现混控饱和；各方向实际差动仍正确，但未饱和样本数为 0 / 3 / 14 / 0，不足以用本次数据评价所有方向的线性增益。577 个运行快照中 520 点四路发布命令与帧锁存 PWM 数值完全相同；其余存在两个发布阶段的差别，未把它们宣称为同拍等价证明。当前顶层 RAW_TELEMETRY_COMMANDS=1，上报 PWM 来自 frame_latched，见 source_snapshot/acg720_ano_port.v:69 和 core/flight_core.v:535。

带动力后的第 5～25 秒有 101 点动作前观察：融合速度 X/Y 均方根约 2.00 / 6.14 mm/s，最大绝对值 4.17 / 14.04 mm/s。未独立确认镜头完全静止，不据此确定振动噪声来源或设置新的验收阈值。

本次 SWC 低档，验证的是自稳纠偏及混控输出方向；光流 XY 控制未激活。PWM 是 FPGA 遥测，并非外部示波器、转速或推力实测。没有新增带桨负载、空中稳定性或曝光对齐的旋转光流补偿验收；不保证装桨后即可正常飞行。
