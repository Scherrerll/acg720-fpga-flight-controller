# B0B3 地面站 P/I 与首次工作台验证

时间为2026-10-26，北京时间。新增 `ground/B0B3`，沿用B0B2 v3遥测接收、监控与日志，增加共享XY速度P/I页面、固定本地API及唯一串口所有者中的A590/A591收发。原固件、编译证据和旧地面站未修改。使用步骤见[操作说明](../../docs/XY_PI_GROUND_STATION.md)。

## 修改与取舍

- 页面区分设备最后读回和编辑草稿；成对提交P/I，范围0～1、步长0.0001。默认值按钮只改草稿。仅本次上电有效，不写Flash。
- 收发共用一个串口线程，A591进入原统一分包器后单独分发，不能刷新主遥测的解锁、PWM或新鲜度。
- 查询响应确认B0B3能力；停机检查、连接代次、参数generation和请求ID共同限制提交。发送前重新检查停机；FPGA在实际提交边沿作最终裁决。
- SET保持忙碌至ACK后独立GET核对完整P/I及generation；断线、重启和未知结果使写入资格失效。没有自动SET重试。
- 本地固定API要求正确Host/Origin与独立会话token；token不进入公开遥测、日志或分享链路。USB镜像保持只读。默认不启用参数写入，需显式 `--enable-xy-pi`。
- 为兼容旧解析，主遥测仍上报B0B2；JTAG UserCode和A591参数能力分别证明实际B0B3安装与接口能力。界面同时标明此区别。

实现未扩大成飞行遥控、电机命令、Flash保存或其他增益入口。两个水平轴继续共用一对参数，符合本次接口要求。旧固件不能只靠升级网页获得参数功能。

## 离线验证与及时修复

`python -B -m unittest discover -s ground/B0B3 -p 'test_xy_pi_*.py' -v`：53项通过、实际退出0。覆盖纯状态机、真实Host/Recorder/分包器的假串口链路、临时本地HTTP服务、停机资格撤销、旧连接响应、部分写入、丢ACK/回读及未知结果恢复。Node测试执行实际HTML/JS，覆盖界面动作、十进制输入、草稿、token/epoch/generation、HTTP错误与无重试；通过、退出0。44项执行输入的前后SHA一致。原始回执和日志在 `offline/`，原回执中的 `out/...` 路径保留为采集来源，不表示导出后相同位置必然存在。

独立审查发现超长Content-Length可触发Python整数转换异常；主线已在转换前限制十进制长度，并增加回归。非ASCII token及Content-Length、未知连接错误的HTTP映射也在联调前修正。保留原冻结固件与其验收记录。

## 获授权的实机过程

用户当次确认已拆桨、CH5低位，明确允许B0B3 SRAM下载与默认P/I地面验证，不允许写Flash。下载器实际为VID0403/PID6014、serial6；电台COM17、VID0403/PID6015、serial DU0ENI02A。下载前新鲜遥测未解锁、控制关闭、CH3/CH5/CH7低、四路PWM与命令均1000μs。程序每次读取当前设备清单和下载线位置，不复用历史location。

08:30:16～08:30:25执行固定操作0/2/0（读身份、SRAM Program、读身份），实际退出0。所选FS SHA256为 `a5b893b25a5e510348c8a4ac75c914b8a14473bbfb054b4cc4040b86800f64dd`，下载后ID `0001481B`、UserCode `0000B0B3`。安装脚本仅复用SHA绑定的旧低层操作0/2，不调用硬编码旧V15镜像或B0B2验收的安装器入口。固件包原README的“offline / NOT installed”描述原导出时状态；本次授权后的新增证据单独封存，不改原文件。

08:31首次GET成功P500/I0、generation0。最初临时验证脚本把API中的十六进制build字符串误当整数，断言失败；修正脚本后继续，首次失败未发SET。随后默认SET序号1973207150本地写入16字节，但未收到响应，3秒后显示unknown。没有自动重发；显式恢复GET返回同一启动代次的P500/I0、generation0。

08:32:56在新鲜停机状态下发起新独立事务：GET序号1973207152返回generation0；SET序号1973207153收到OK ACK；独立GET序号1973207154返回同一对P500/I0、generation1，整笔0.71秒通过。没有改成非默认增益，没有执行Flash操作。随后从真实网页点击查询，也显示B0B3、P0.0500/I0.0000、generation1及查询完成。

上述默认值验收之后，用户在地面站手动设置P=0.0750、I=0，并在聊天中明确确认该操作来自本人。对应SET序号1973207158及独立GET序号1973207159均返回OK、P750/I0、generation2。代理未发起该非默认写入，也未覆盖用户的新值；这另证实页面能完成一次实际非默认参数事务，不代表该增益的控制效果或飞行安全性已验证。

## 首笔无响应的调查边界

两项独立只读复核均未定位到确定软件/RTL缺陷。原始接收流前626766字节（SHA256 `47edf558535eeb5493ab2a29819aebbcc10f677069c276a07df30f53e50ac55c`）仅有3个完整A591，均为GET，没有首笔SET响应头或序号。按原chunks重放实际分包器结果一致，SET前后5秒无解码错误、断线或重启。该序号请求CRC正确；本地write16成功不证明电台或FPGA收齐。

恢复GET的generation0说明首笔未提交。附近存在遥测缺帧，但不足以断言RF丢包；仍不能区分上行未成帧与拒绝回复在下行丢失。源码中同值SET也会提交并增加generation，CRC/停机否决均应回复，第二笔真实成功也排除了“同值SET必然失败”。因此保留失败证据、先查询恢复，未凭猜测修改已资格化RTL，也未把未知结果当成功。

## 证据与限制

`bench/`保存安装回执、0/2/0输出、两次事务、恢复查询、相关脚本及截图。`wire/`提取对应收发事件与已解码A591，并记录首次失败原始流前缀的SHA及本地采集位置；原始流、原始前缀、完整chunks和完整持续采集留在忽略目录 `ground/runtime/B0B3`，不随源码上传。`manifest.json`绑定本次新增地面站、说明、测试和证据的SHA256；仅清单本身及其sidecar不自绑定。

代理完成默认参数地面通路验证，用户随后完成一次非默认值的页面事务；均不证明非默认参数的数值效果、连续链路可靠性、飞行动态、重启后保持B0B3或Flash安装。SRAM易失；原Flash保持P005/I0基线。参数数值范围仅为协议边界，不是全范围飞行资格。旧两日归档清单作为历史记录保留不改。

归档中的bench脚本是当次采集过程的原件，不是通用安装入口；不要在归档目录重跑、覆写回执或复用其中的历史授权描述。后续硬件操作重新核对现场状态、设备身份和本次操作范围。
